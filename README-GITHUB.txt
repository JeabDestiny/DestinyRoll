# Destiny Roll ✦ JeabJeab

เว็บไซต์สุ่ม Loadout สำหรับ Delta Force ทำงานแบบ Static Website เหมาะกับ GitHub Pages

## ไฟล์ในโปรเจกต์
- `index.html` — โครงสร้างหน้าเว็บ
- `style.css` — ธีม สี และ responsive layout
- `script.js` — รายชื่อ Operator / ปืน และระบบสุ่ม
- `background.png` — ภาพพื้นหลัง JeabJeab ที่ให้มา
- `Jeablogo.png` — โลโก้ JeabJeab ที่ให้มา
- `favicon.png` — ไอคอนแท็บเว็บ

## วิธีอัปโหลดขึ้น GitHub Pages
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง root ของ repository (ให้อยู่ระดับเดียวกับ `index.html`)
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch** แล้วเลือก branch `main` และ folder `/ (root)`
5. กด Save และรอ GitHub Pages เผยแพร่เว็บไซต์

## วิธีใช้
- ติ๊กสาย Operator และประเภทปืนที่อนุญาตให้สุ่ม
- เลือกระดับสีของหมวกและเกราะแยกกันได้
- กด **หมุน** เพื่อสุ่มหนึ่งรอบ
- กดค้าง **กดค้าง** เพื่อหมุนต่อเนื่อง และปล่อยเพื่อหยุด
- กด **หมุนทั้งหมด** เพื่อสุ่มทั้ง 4 ช่อง

## หมายเหตุ
รายชื่อ Operator และปืนเป็นข้อมูลตั้งต้นที่อาจต้องตรวจสอบกับแพตช์/โหมดเกมปัจจุบันก่อนใช้จริง
